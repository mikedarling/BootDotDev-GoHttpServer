# Boot.Dev - Learn HTTP Servers in Go

Repository that contains the code reflecting the work in the Boot.dev's [Go HTTP Server](https://www.boot.dev/courses/learn-http-servers-golang) course.

- Chapter and Lessons broken out by folder as opposed to using commits or features. 
- I did not make much effort to refactor any reusable components or other engineering best practices.

The "Refactored" folder at the bottom is my attempt to clean it up some. There are probably a bunch of packages available to handle things like route mapping and working with auth tokens, but I was just looking to be more "hands-on" with the language itself.
